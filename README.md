# Belajar TypeScript

Selamat datang di repositori **Belajar TypeScript**! Kursus ini dirancang untuk membantu Anda memahami konsep dasar hingga lanjutan dalam penggunaan TypeScript, sebuah superset dari JavaScript yang menambahkan sistem tipedata statis.

Docsify adalah generator situs dokumentasi yang ringan dan mudah digunakan, tidak memerlukan _build configuration_ yang rumit. Cukup tulis dokumentasi Anda dalam Markdown, dan Docsify akan mengubahnya menjadi situs web yang indah.

## Struktur Kursus

Kursus ini disusun secara sistematis dari konsep dasar hingga topik-topik lanjutan:

- `001-PendahuluanDanSetupLingkungan.md`: Pengenalan dan setup lingkungan TypeScript
- `002-TipeDataDanTypeSystemFundamentals.md`: Tipe data dan sistem tipe fundamental
- `003-FunctionsDanAsyncProgramming.md`: Fungsi dan pemrograman asinkron
- `004-OOP.md`: Pemrograman berorientasi objek
- `005-GenericsDanTypeConstraints.md`: Generics dan kendala tipe
- `006-AdvancedTypesDanTypeManipulation.md`: Tipe lanjutan dan manipulasi tipe
- `007-UtilityTypesDanTypeTransformations.md`: Utility types dan transformasi tipe
- `008-ModulesDanCodeOrganization.md`: Modul dan organisasi kode
- `009-DecoratorsDanAdvancedPatterns.md`: Decorators dan pola lanjutan
- `0010-FinalSession.md`: Rangkuman dan sesi akhir

## Cara Menggunakan Proyek Ini

1.  **Kloning Repositori**: Dapatkan salinan proyek ini ke mesin lokal Anda.
2.  **Jalankan Docsify**: Instal Docsify CLI (`npm i docsify-cli -g`) dan jalankan `docsify serve` di direktori proyek Anda untuk melihat situs dokumentasi Anda secara lokal. Atau cara paling mudah gunakan live-server di editor yang anda pakai.
3.  **Mulai Belajar**: Akses dokumentasi melalui browser dan mulai belajar TypeScript dari dasar hingga mahir!

## Struktur Proyek

- `index.html`: File utama yang memuat Docsify dan konfigurasi situs Anda.
- `README.md`: Halaman beranda dokumentasi Anda.
- `home.md`: Halaman beranda utama untuk kursus.
- `_sidebar.md`: Mengatur navigasi sidebar situs Anda.
- `style.css`: Kustomisasi gaya tambahan untuk tampilan yang lebih menarik.
