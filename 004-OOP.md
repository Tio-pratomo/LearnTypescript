# Object-Oriented Programming (OOP)

Object-Oriented Programming (OOP) adalah paradigma pemrograman yang berpusat pada konsep **objek**. TypeScript dirancang dengan dukungan penuh untuk paradigma ini, membuatnya ideal untuk aplikasi skala besar.

## Apa itu OOP?

OOP adalah cara berpikir dan merancang kode dengan mengorganisir program menjadi **objek** yang merepresentasikan entitas di dunia nyata. Setiap objek memiliki:

**Properties (Properti)** — Data atau state yang dimiliki objek (misalnya mobil punya `warna`, `merk`, `tahun`).

**Methods (Metode)** — Aksi atau perilaku yang dapat dilakukan objek (misalnya mobil bisa `maju()`, `mundur()`, `mengerem()`).

### Empat Pilar OOP

**Encapsulation (Enkapsulasi)** — Menyembunyikan detail implementasi internal dan hanya expose yang diperlukan.

**Inheritance (Pewarisan)** — Membuat class baru berdasarkan class yang sudah ada, mewarisi properties dan methods.

**Polymorphism (Polimorfisme)** — Objek berbeda dapat merespons perintah yang sama dengan cara berbeda.

**Abstraction (Abstraksi)** — Menyembunyikan kompleksitas dan hanya menampilkan fungsionalitas penting.

## Class: Blueprint untuk Objek

Class adalah cetak biru untuk membuat objek dengan struktur dan perilaku yang sama.

### Properti, Constructor, dan Method

```typescript
class Mobil {
  // Properties (dengan type annotation):
  merk: string;
  warna: string;
  tahun: number;
  kecepatanSaatIni: number;

  // Constructor - dijalankan saat objek dibuat:
  constructor(merk: string, warna: string, tahun: number) {
    this.merk = merk;
    this.warna = warna;
    this.tahun = tahun;
    this.kecepatanSaatIni = 0;
  }

  // Methods:
  maju(): void {
    this.kecepatanSaatIni += 10;
    console.log(
      `${this.merk} bergerak maju. Kecepatan: ${this.kecepatanSaatIni} km/h`
    );
  }

  berhenti(): void {
    this.kecepatanSaatIni = 0;
    console.log(`${this.merk} berhenti.`);
  }

  info(): string {
    return `${this.merk} ${this.warna} (${this.tahun})`;
  }
}

// Membuat instance (objek) dari class:
const mobil1 = new Mobil("Toyota", "Merah", 2020);
const mobil2 = new Mobil("Honda", "Hitam", 2022);

mobil1.maju(); // Toyota bergerak maju. Kecepatan: 10 km/h
mobil1.maju(); // Toyota bergerak maju. Kecepatan: 20 km/h
console.log(mobil1.info()); // Toyota Merah (2020)
```

### Shorthand Constructor Parameters

TypeScript menyediakan syntax yang lebih ringkas untuk define dan assign properties:

```typescript
class User {
  // Shorthand: langsung define properties di constructor
  constructor(
    public id: number,
    public name: string,
    public email: string,
    private password: string // private property
  ) {
    // Tidak perlu this.id = id, dll - otomatis!
  }

  getInfo(): string {
    return `${this.name} (${this.email})`;
  }
}

const user = new User(1, "Budi", "budi@example.com", "secret123");
console.log(user.name); // ✅ Accessible
// console.log(user.password);  // ❌ Error: Property 'password' is private
```

## Access Modifiers (Enkapsulasi)

Access modifiers mengontrol visibility properties dan methods:

### Public (Default)

Accessible dari mana saja:

```typescript
class Person {
  public name: string; // Explicit public
  age: number; // Implicitly public

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}

const person = new Person("Andi", 25);
console.log(person.name); // ✅ Accessible
console.log(person.age); // ✅ Accessible
```

### Private

Hanya accessible di dalam class itu sendiri:

```typescript
class BankAccount {
  private balance: number = 0;

  constructor(initialBalance: number) {
    this.balance = initialBalance;
  }

  deposit(amount: number): void {
    if (amount > 0) {
      this.balance += amount;
      console.log(`Deposited: ${amount}. New balance: ${this.balance}`);
    }
  }

  getBalance(): number {
    return this.balance; // ✅ Accessible within class
  }
}

const account = new BankAccount(1000);
account.deposit(500);
console.log(account.getBalance()); // 1500
// console.log(account.balance);    // ❌ Error: Property 'balance' is private
```

**Hard Private dengan `#`** (ECMAScript Private Fields):

```typescript
class SecureVault {
  #secretCode: string; // ECMAScript private

  constructor(code: string) {
    this.#secretCode = code;
  }

  unlock(code: string): boolean {
    return code === this.#secretCode;
  }
}

const vault = new SecureVault("abc123");
console.log(vault.unlock("abc123")); // true
// console.log(vault.#secretCode);    // ❌ Syntax error (even at runtime!)
```

### Protected

Accessible di dalam class dan **subclass** (turunannya):

```typescript
class Employee {
  protected salary: number;

  constructor(salary: number) {
    this.salary = salary;
  }

  protected calculateBonus(): number {
    return this.salary * 0.1;
  }
}

class Manager extends Employee {
  showTotalCompensation(): void {
    // ✅ Can access protected members from parent:
    const bonus = this.calculateBonus();
    console.log(`Total: ${this.salary + bonus}`);
  }
}

const manager = new Manager(5000);
manager.showTotalCompensation();
// console.log(manager.salary);  // ❌ Error: Property 'salary' is protected
```

## Inheritance (Pewarisan)

Membuat class baru yang mewarisi properties dan methods dari class lain:

```typescript
// Parent class (superclass):
class Animal {
  constructor(public name: string) {}

  makeSound(): void {
    console.log("Some generic animal sound");
  }

  move(distance: number): void {
    console.log(`${this.name} moved ${distance} meters`);
  }
}

// Child class (subclass) extends parent:
class Dog extends Animal {
  constructor(name: string, public breed: string) {
    super(name); // ⚠️ Harus call parent constructor!
  }

  // Override parent method:
  makeSound(): void {
    console.log("Woof! Woof!");
  }

  // Add new method:
  fetch(): void {
    console.log(`${this.name} is fetching the ball`);
  }
}

class Cat extends Animal {
  makeSound(): void {
    console.log("Meow!");
  }
}

// Usage:
const dog = new Dog("Buddy", "Golden Retriever");
dog.makeSound(); // Woof! Woof! (overridden)
dog.move(10); // Buddy moved 10 meters (inherited)
dog.fetch(); // Buddy is fetching the ball (new method)

const cat = new Cat("Whiskers");
cat.makeSound(); // Meow! (overridden)
cat.move(5); // Whiskers moved 5 meters (inherited)
```

### Super Keyword

`super` digunakan untuk memanggil constructor atau method dari parent class:

```typescript
class Vehicle {
  constructor(public brand: string) {}

  startEngine(): void {
    console.log(`${this.brand} engine started`);
  }
}

class Car extends Vehicle {
  constructor(brand: string, public model: string) {
    super(brand); // Call parent constructor
  }

  startEngine(): void {
    super.startEngine(); // Call parent method
    console.log(`${this.model} is ready to drive`);
  }
}

const car = new Car("Toyota", "Camry");
car.startEngine();
// Toyota engine started
// Camry is ready to drive
```

## Interface: Kontrak untuk Structure

Interface mendefinisikan **kontrak** yang harus dipenuhi oleh class atau object:

```typescript
interface Vehicle {
  brand: string;
  year: number;
  start(): void;
  stop(): void;
}

// Class implements interface:
class Car implements Vehicle {
  constructor(public brand: string, public year: number) {}

  start(): void {
    console.log(`${this.brand} started`);
  }

  stop(): void {
    console.log(`${this.brand} stopped`);
  }

  // ✅ Can have additional properties/methods:
  accelerate(): void {
    console.log("Accelerating...");
  }
}

const myCar: Vehicle = new Car("Honda", 2023);
myCar.start();
// myCar.accelerate();  // ❌ Error: Property 'accelerate' doesn't exist on type 'Vehicle'
```

### Multiple Interface Implementation

Class dapat implement **multiple interfaces** (tidak seperti inheritance):

```typescript
interface Flyable {
  fly(): void;
  altitude: number;
}

interface Swimmable {
  swim(): void;
  depth: number;
}

// Implement multiple interfaces:
class Duck implements Flyable, Swimmable {
  altitude: number = 0;
  depth: number = 0;

  fly(): void {
    this.altitude = 100;
    console.log(`Flying at ${this.altitude}m`);
  }

  swim(): void {
    this.depth = 2;
    console.log(`Swimming at ${this.depth}m depth`);
  }
}

const duck = new Duck();
duck.fly();
duck.swim();
```

### Interface Extension

Interface dapat extend interface lain:

```typescript
interface Person {
  name: string;
  age: number;
}

interface Employee extends Person {
  employeeId: string;
  department: string;
}

// Must implement all properties from Person AND Employee:
const employee: Employee = {
  name: "Budi",
  age: 30,
  employeeId: "EMP001",
  department: "IT",
};
```

## Abstract Classes

Abstract class adalah class yang **tidak bisa di-instantiate** dan biasanya digunakan sebagai base class:

```typescript
abstract class Shape {
  constructor(public name: string) {}

  // Abstract method (must be implemented by subclass):
  abstract calculateArea(): number;

  // Concrete method (already implemented):
  describe(): void {
    console.log(`This is a ${this.name} with area: ${this.calculateArea()}`);
  }
}

// ❌ Cannot instantiate abstract class:
// const shape = new Shape("Generic");  // Error!

class Circle extends Shape {
  constructor(public radius: number) {
    super("Circle");
  }

  // ✅ Must implement abstract method:
  calculateArea(): number {
    return Math.PI * this.radius ** 2;
  }
}

class Rectangle extends Shape {
  constructor(public width: number, public height: number) {
    super("Rectangle");
  }

  calculateArea(): number {
    return this.width * this.height;
  }
}

const circle = new Circle(5);
circle.describe(); // This is a Circle with area: 78.54

const rectangle = new Rectangle(4, 6);
rectangle.describe(); // This is a Rectangle with area: 24
```

### Abstract Class vs Interface

| Aspek              | **Abstract Class**                                 | **Interface**                                   |
| ------------------ | -------------------------------------------------- | ----------------------------------------------- |
| **Instantiation**  | ❌ Tidak bisa di-instantiate                       | ❌ Tidak bisa di-instantiate                    |
| **Implementation** | ✅ Bisa punya concrete methods                     | ❌ Hanya signatures (no implementation)         |
| **Properties**     | ✅ Bisa punya properties dengan values             | ⚠️ Hanya define types                           |
| **Constructor**    | ✅ Bisa punya constructor                          | ❌ Tidak bisa punya constructor                 |
| **Inheritance**    | ⚠️ Class hanya bisa extend **satu** abstract class | ✅ Class bisa implement **multiple** interfaces |
| **Runtime**        | ✅ Exists at runtime (compiled to JS)              | ❌ Compile-time only (tidak ada di JS)          |
| **Use Case**       | Shared behavior + enforced structure               | Pure contracts/shapes                           |

**Kapan menggunakan Abstract Class?**

- Butuh shared implementation (reusable code)
- Butuh constructor atau state management
- Relationship adalah "is-a" (inheritance)

**Kapan menggunakan Interface?**

- Hanya define structure/contract
- Perlu multiple implementations
- Relationship adalah "can-do" (capabilities)

```typescript
// Example combining both:
interface Printable {
  print(): void;
}

abstract class Document implements Printable {
  constructor(public title: string) {}

  abstract getContent(): string;

  // Shared implementation:
  print(): void {
    console.log(`Title: ${this.title}`);
    console.log(`Content: ${this.getContent()}`);
  }
}

class Report extends Document {
  constructor(title: string, private data: string) {
    super(title);
  }

  getContent(): string {
    return this.data;
  }
}

const report = new Report("Q4 Sales", "Sales increased by 20%");
report.print();
```

## Readonly Properties

Properties yang hanya bisa di-set saat initialization:

```typescript
class User {
  readonly id: number;
  readonly createdAt: Date;

  constructor(id: number, public name: string) {
    this.id = id;
    this.createdAt = new Date();
  }

  updateName(newName: string): void {
    this.name = newName; // ✅ OK
    // this.id = 999;     // ❌ Error: Cannot assign to 'id' because it is read-only
  }
}

const user = new User(1, "Budi");
// user.id = 2;  // ❌ Error: Cannot assign to 'id'
```

## Static Members

Properties dan methods yang belong to class itself, bukan instance:

```typescript
class MathHelper {
  static PI: number = 3.14159;

  static square(n: number): number {
    return n * n;
  }

  static cube(n: number): number {
    return n * n * n;
  }
}

// Access tanpa instantiation:
console.log(MathHelper.PI); // 3.14159
console.log(MathHelper.square(5)); // 25
console.log(MathHelper.cube(3)); // 27

// ❌ Cannot access via instance:
// const helper = new MathHelper();
// console.log(helper.PI);  // Error
```

## Getters dan Setters

Accessor methods untuk controlled access ke properties:

```typescript
class Temperature {
  private _celsius: number = 0;

  // Getter:
  get celsius(): number {
    return this._celsius;
  }

  // Setter:
  set celsius(value: number) {
    if (value < -273.15) {
      throw new Error("Temperature below absolute zero!");
    }
    this._celsius = value;
  }

  // Computed property via getter:
  get fahrenheit(): number {
    return (this._celsius * 9) / 5 + 32;
  }

  set fahrenheit(value: number) {
    this._celsius = ((value - 32) * 5) / 9;
  }
}

const temp = new Temperature();
temp.celsius = 25; // Calls setter
console.log(temp.celsius); // 25 (calls getter)
console.log(temp.fahrenheit); // 77

temp.fahrenheit = 100;
console.log(temp.celsius); // 37.78
```

## Composition Over Inheritance

Best practice modern: prefer **composition** over inheritance untuk flexibility:

```typescript
// Instead of deep inheritance hierarchies...
// Prefer composition:

interface Logger {
  log(message: string): void;
}

interface Database {
  save(data: any): void;
}

class ConsoleLogger implements Logger {
  log(message: string): void {
    console.log(`[LOG] ${message}`);
  }
}

class FileDatabase implements Database {
  save(data: any): void {
    console.log(`Saving to file: ${JSON.stringify(data)}`);
  }
}

// Use composition:
class UserService {
  constructor(private logger: Logger, private database: Database) {}

  createUser(name: string): void {
    this.logger.log(`Creating user: ${name}`);
    this.database.save({ name });
    this.logger.log("User created successfully");
  }
}

// Easy to swap implementations:
const service = new UserService(new ConsoleLogger(), new FileDatabase());

service.createUser("Budi");
```

## Best Practices

**Prefer Composition** — Lebih flexible daripada deep inheritance.

**Use Interfaces Liberally** — Define contracts untuk better abstraction.

**Encapsulation** — Keep properties private, expose via methods.

**Single Responsibility** — Each class should have one clear purpose.

**Abstract for Shared Logic** — Use abstract classes untuk reusable behavior.

## Ringkasan

**Class** — Blueprint untuk objek dengan properties, constructor, dan methods.

**Access Modifiers** — `public`, `private`, `protected` untuk encapsulation.

**Inheritance** — `extends` untuk mewarisi dari parent class.

**Interface** — Define contracts, bisa multiple implementation.

**Abstract Class** — Base class dengan shared implementation + enforced structure.

**Composition** — Prefer "has-a" relationships over "is-a" untuk flexibility.
